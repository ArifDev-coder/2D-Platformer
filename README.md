# 2D Platformer Basics

A 2D platformer built in **Godot 4.7 (C#)** with a state-machine player
controller (idle / run / jump / fall / crouch / die), patrol enemies,
coyote time, variable jump height, sprint, skid, and crouch.

**Docs:** start at [docs/index.md](docs/index.md) — controls, gameplay,
player state machine, enemies, levels, tuning guide, and known gaps.

**Run it:** open the folder in Godot 4.7+ with .NET support and run
`main.tscn`. Move `A/D`, jump `Space`, sprint `Enter`, crouch `S`.
